# Scope and limitations

The main theorem concerns one unbounded family of finite simple cubic 3-connected graphs, uniform counting on the original edge variables and a fixed relative error below one. The overlap of accepting branches is allowed. At error one the false constant is a valid approximation. Arbitrary nonuniform input distributions and encodings with additional variables are outside the result.

For a nonempty affine binary code the ordinary bound counts gates after polynomial-cost normalization. It gives an exponential branchwidth lower bound at fixed strong error after that normalization. The structured lower bound uses the actual width of a supplied vtree, and the upper bound constructs an exact circuit from that vtree. A one-variable code is treated as a one-gate lower-bound case. The results leave the sharp general exponents and the problem of finding an optimal vtree open.

The exact replay checks finite cases, including circuits on small affine codes. The general argument is in the manuscript. The [Lean certificate](formalization/README.md) checks a supporting result. External peer review is pending.
