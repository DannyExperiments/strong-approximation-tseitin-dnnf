# Mathematical audit

The hard cut is chosen separately for each trace vtree. Its exact rectangle bound uses the split graph's incidence rank and a conservative cubic independent-set constant. After root padding and OR smoothing, a trace has exactly one literal per variable. At the selected gate, decomposability separates its variable set from all AND siblings above it. The union over trace contexts preserves a product on that cut.

In a mixed rectangle, each true matching-syndrome block is itself a true rectangle. The Cauchy–Schwarz estimate uses the false-positive budget for that individual mixed rectangle. The gate cover sums only true coverage, so the same false positive may legitimately occur in several rectangles.

For affine codes the compatible syndrome set is an affine translate of the image intersection. Rank-nullity gives equal-sized diagonal and cross-tiles. Sampling a pair in each diagonal tile gives uniform cross-pairs between distinct tiles. The independent-set argument uses the fixed-cut theorem for structured DNNF. A one-variable instance has width zero and the resulting bounds are at most one, also for constant circuits. The exact circuit construction uses only extendible syndromes, with disjoint assignments for different child-state pairs.
